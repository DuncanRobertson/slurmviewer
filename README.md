# slurmviewer

This project is hosted on Codeberg:

### **[https://codeberg.org/DuncanRobertson/slurmviewer](https://codeberg.org/DuncanRobertson/slurmviewer)**

A small read-only web view of a SLURM cluster: the current queue plus recent
job history in one table, with cluster utilisation, filters, auto-refresh and
CSV export, and a live node/CPU-core visualizer. Reads the SLURM REST API via
`slurmrestd` rather than parsing `squeue` and `sacct` output.
